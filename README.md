# ObjectSpotter

Простой API для распознавания объектов на изображении. Построен на FastAPI и YOLOv8: пользователь загружает картинку и получает список найденных объектов с координатами.

## Возможности

- Загрузка изображения через веб-страницу или API
- Определение объектов (80 классов COCO: человек, машина, собака и т.д.)
- Ответ в JSON: название, уверенность, координаты рамки

## Технологии

Python, FastAPI, Uvicorn, Ultralytics YOLOv8, Pillow

## Установка и запуск

```bash
pip install -r req.txt
python main.py
```

Открой в браузере `http://127.0.0.1:8000/`. При первом запуске модель `yolov8m.pt` скачается автоматически.

Документация API (Swagger): `http://127.0.0.1:8000/docs`

## API

**POST `/detect`**

| Параметр | Тип | Описание |
|---|---|---|
| `file` | файл | изображение (jpg, png и др.) |
| `conf` | число | порог уверенности, по умолчанию 0.30 |

Пример запроса:

```bash
curl -X POST http://127.0.0.1:8000/detect -F "file=@dog.jpg"
```

Пример ответа:

person 86%
dog 53%
